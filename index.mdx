Jetic is an AI-native CLI tool that statically analyzes your Express TypeScript backend, builds a versioned Behavioral Model of every endpoint, and uses AI to generate and execute intelligent multi-step workflow tests — all without booting your server. From a single `jetic scan`, you get a complete map of your API and the power to simulate real user journeys in seconds.

## How Jetic Works

Get from zero to simulated API workflows in four steps.

<Steps>
  <Step title="Install">
    Install the `jetic` CLI globally with your preferred package manager.

    ```bash
    npm install -g @jetic/cli
    ```
  </Step>
  <Step title="Initialize">
    Run `jetic init` inside your project root. Jetic prompts you for your AI provider, model, and API key, then writes `.jetic/config.json`.

    ```bash
    cd your-project && jetic init
    ```
  </Step>
  <Step title="Scan">
    Jetic reads your TypeScript source using AST parsing — no server needed. It discovers every Express route, extracts parameters and constraints, and writes the result to `.jetic/model.json`.

    ```bash
    jetic scan
    ```
  </Step>
  <Step title="Simulate">
    Run AI-powered endpoint tests or generate full multi-step workflow simulations against your live server.

    ```bash
    jetic simulate workflow --goal "User registers, logs in, and places an order"
    ```
  </Step>
</Steps>
