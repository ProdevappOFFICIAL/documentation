The Jetic CLI gives you everything you need to analyze, inspect, and test your Express TypeScript backend from the terminal. After installing the package globally, you can initialize a project, scan its routes into a versioned Behavioral Model, and immediately run AI-generated end-to-end workflow simulations — all without starting a server.

## Installation

Install the CLI globally with npm:

```bash
npm install -g @jetic/cli
```

Jetic requires **Node.js 20 or later**. After installation, verify the CLI is available:

```bash
jetic --version
```

## Commands Table

| Command | Description | Key Flags |
|---|---|---|
| `jetic init` | Interactive setup wizard: configures your AI provider, model, and API key, then creates `.jetic/config.json` | — |
| `jetic scan` | Performs static AST analysis of your project and writes the Behavioral Model to `.jetic/model.json` | — |
| `jetic inspect` | Lists all discovered endpoints from `model.json`; drill into a specific route with the `endpoint` subcommand | — |
| `jetic simulate endpoint` | Sends real HTTP requests to your running server for a single endpoint or all endpoints at once | `--all`, `--verbose` |
| `jetic simulate workflow` | Uses AI to generate a multi-step workflow test and executes it sequentially against your server | `--goal`, `--env`, `--workflow`, `--generate-only`, `--clear-memory` |
| `jetic memory` | Lists, adds, or clears scoped key-value entries used to pass data between workflow steps | — |
| `jetic config` | Displays current configuration; `config ai` subcommand updates your AI provider, model, or API key variable | `--provider`, `--model`, `--key-env` |
| `jetic dev` | Starts Jetic Studio — a local browser dashboard for exploring your model, running simulations, and inspecting memory | `--port` |

## Global Usage

Get inline help for the CLI or any individual command:

```bash
# Top-level help
jetic --help

# Command-specific help
jetic <command> --help

# Print the installed version
jetic --version
```
